| 지표 | 명령 | 비교 |
|---|---|---|
| 추론 건전성 (사망률 0%) | `python main.py --random 1000 --policy safe` | safe 정책 사망 0건 확인 |
| 성공률 · 평균 점수 | `--random 1000` (seed 0~999) | 해결 가능 세계 747개 대비 성공률도 같이 |

| 가지치기 효과 | 기본 / `--no-prune` | ASK 시간, 기호 수 |
| DPLL 휴리스틱 (가산점) | 2-3 · 2-4 켜기/끄기 | DPLL 호출 수, 시간 |
| 행동 정책 | `--policy safe` / `--policy risk` | 성공률, 사망률, 평균 점수 |
| 기준선 | `--agent random` | 성공률, 평균 점수 |
